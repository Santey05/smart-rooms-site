# Смарт румс — сайт мини-отеля

Контентный сайт со встроенным модулем бронирования Bnovo. Полное описание
архитектуры и принятых решений — в [`CLAUDE.md`](./CLAUDE.md), это основной
рабочий документ проекта.

## Стек

Next.js (App Router) · React · TypeScript · Tailwind CSS v4 · shadcn/ui
(компоненты добавлены вручную, см. ниже) · pnpm.

## Локальный запуск

```bash
pnpm install
cp .env.example .env.local   # уже сделано в репозитории для разработки
pnpm dev
```

Открыть http://localhost:3000. Страница `/booking` встраивает модуль
бронирования Bnovo — для него нужен `NEXT_PUBLIC_BNOVO_UID` в `.env.local`.

## Проверки перед коммитом

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## О shadcn/ui в этом репозитории

Официальный CLI (`pnpm dlx shadcn init`) обращается к `ui.shadcn.com`, что в
некоторых окружениях (например, в песочнице этой сессии) заблокировано
политикой сети. Поэтому базовые компоненты (`Button`, `Input`, `Label`,
`Card`) добавлены вручную как исходники — это штатный способ работы
shadcn/ui, файлы лежат в `src/components/ui/`. `components.json` в корне
описывает конфигурацию на случай, если в окружении с доступом к сети
понадобится добавить новый компонент через `pnpm dlx shadcn@latest add
<component>`.
